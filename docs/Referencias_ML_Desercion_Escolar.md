### 1. Student dropout prediction through machine learning optimization: insights from moodle log data
- **Año:** 2025
- **Revista:** Scientific Reports (Nature) — Acceso abierto
- **Resumen:** Usa el algoritmo CatBoost entrenado con registros de actividad de la plataforma Moodle. Incorpora técnicas de balanceo de datos y optimización con algoritmo genético para mejorar la predicción de deserción y fracaso académico.
- **Enlace:** https://www.nature.com/articles/s41598-025-93918-1
- **PMC (acceso abierto):** https://pmc.ncbi.nlm.nih.gov/articles/PMC11928464/

### 2. Predicting student dropouts with machine learning: An empirical study in Finnish higher education
- **Año:** 2024
- **Revista:** Technology in Society (ScienceDirect)
- **Resumen:** Compara tres modelos de ML para predecir deserción estudiantil usando datos de expedientes académicos, datos demográficos y del sistema de gestión del aprendizaje (LMS) en una universidad finlandesa. Analiza la importancia de las características mes a mes durante el año académico.
- **Enlace:** https://www.sciencedirect.com/science/article/pii/S0160791X24000228

### 4. An explainable machine learning approach for student dropout prediction
- **Año:** 2023
- **Revista:** Expert Systems with Applications (ScienceDirect)
- **Resumen:** Aplica machine learning interpretable (XAI) para predecir la deserción usando datos de 19 escuelas en Brasil. Destaca la importancia de la explicabilidad en modelos educativos.
- **Enlace:** https://www.sciencedirect.com/science/article/abs/pii/S0957417423014355

### 5. Supervised machine learning algorithms for predicting student dropout and academic success: a comparative study
- **Año:** 2023
- **Revista:** Discover Artificial Intelligence (Springer) — Acceso abierto
- **Resumen:** Estudio comparativo de algoritmos supervisados de ML. Emplea remuestreo, aprendizaje sensible al costo, algoritmos ensemble y detección de anomalías no supervisada para predecir el abandono estudiantil.
- **Enlace:** https://link.springer.com/article/10.1007/s44163-023-00079-z

### 6. Predicting Student Dropout based on Machine Learning and Deep Learning: A Systematic Review
- **Año:** 2023
- **Revista:** EAI Endorsed Transactions on Scalable Information Systems — Acceso abierto
- **Resumen:** Revisión sistemática de algoritmos de ML y DL para predecir deserción. Cubre 246 artículos de Scopus, IEEE y Web of Science hasta junio de 2023. Encuentra que Random Forest es el algoritmo más usado (21.73%) con hasta 99% de precisión.
- **Enlace:** https://publications.eai.eu/index.php/sis/article/view/3586
- **ResearchGate:** https://www.researchgate.net/publication/372493356_Predicting_Student_Dropout_based_on_Machine_Learning_and_Deep_Learning_A_Systematic_Review
